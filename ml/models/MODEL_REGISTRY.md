# Model artifact registry

Trained model artifacts land here as `{model_name}_{version}.json` (XGBoost
native format) plus a matching `{model_name}_{version}_scaler.json` (the
feature `StandardScaler`'s mean/scale, needed to reproduce predictions).
`version` is a UTC timestamp (`YYYYMMDDTHHMMSSZ`).

Artifacts are **gitignored** (see `.gitignore`) — they're regenerated by
`uv run python -m ml.training.train_match_result` and tracked, with their
metrics, in the `model_versions` / `training_runs` database tables, not in
git. Every training run creates a new artifact; nothing here is ever
overwritten, matching the "never overwrite models" requirement.

To see what's registered: `GET /model/performance` or query
`model_versions` directly.
